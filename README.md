## Abstract

The Smart Adaptive Internship Tracker is a web-based platform designed to help students efficiently manage and track their internship applications. The system provides a centralized solution for storing internship details, application dates, interview schedules, resume versions, deadlines, and application statuses such as Applied, Online Assessment, Interview, Selected, and Rejected. It eliminates the need for manual tracking through spreadsheets or notes, improving organization and reducing the chances of missing important recruitment activities.

The platform includes separate modules for students and administrators. Students can monitor their application progress through a personalized dashboard, while administrators can post internship opportunities, manage company details, and monitor student participation. The system dynamically displays reminders, notifications, and recommendations based on each student's application stage. Developed using React.js, Spring Boot (Java), MySQL, JWT, MLflow, and Docker, the proposed system aims to provide a secure, scalable, and user-friendly solution that enhances internship management and supports students in achieving better career opportunities.
